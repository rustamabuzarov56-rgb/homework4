# Каталог товаров магазина

## Данный проект реализует простейшую систему управления товарами и категориями в онлайн-магазине с помощью классов Product и Category.

# Классы
## Проект состоит из двух основных классов:

### 1.Product
### Представляет собой единичный товар с основными свойствами:

|Атрибут|Описание |
|-------|---------|
|name|	Название товара(string)|
|description|	Описание товара(string)|
|price|	Цена товара(float)|
|quantity|	Количество товара на складе(integer)|

### 2.Category
### Представляет категорию товаров, содержащую список товаров:

|Атрибут|Описание |
|--|---------|
|name|	Название категории (string)|
|description|	Описание категории (string)|
|products|	Список товаров в категории (list)|
|category_count|	Общее количество категорий (class attribute)|
|product_count| Общее количество товаров во всех категориях (class attribute)|

## Особенности
Каждая категория ведет учет количества товаров и категорий автоматически.
Поддерживаются типы данных: string, integer и float.
Простота расширения путем наследования или дополнения атрибутов.

## Требования

Для работы с проектом необходима среда Python версии >= 3.7 и библиотека типа typing (стандартная библиотека Python).
